# PhiPortal

**One screen. Everybody connects.**

PhiPortal is an experimental, open-source, local-first collaborative display and screen-sharing project. The goal is a tiny network node that turns an HDMI television or monitor into an opt-in shared display for friends, classrooms, workshops, and other trusted spaces.

Initial direction: browser-first receiver and presenter controls, explicit consent for each screen-sharing session, and eventually an optional HDMI-connected hardware node. The project will distinguish interactive prototypes from verified live streaming and device compatibility.

Development begins through reviewed pull requests. See upcoming work for the first React control-room proof of concept.
